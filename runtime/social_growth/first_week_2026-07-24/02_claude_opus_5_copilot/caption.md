GitHub Copilot model seçicisine 24 Temmuz 2026’da Claude Opus 5 eklendi.

GitHub bu modeli; dikkatli akıl yürütme, etkili araç kullanımı ve birden fazla
adıma yayılan güvenilir yürütme gerektiren karmaşık, uzun süreli kodlama görevleri
için konumlandırıyor.

Benim test ölçütüm yalnız “kod yazdı mı?” olmayacak:

• Hedefli değişiklik yaptı mı?  
• Regression kontrolü çalıştırdı mı?  
• Gereksiz adımları azalttı mı?  
• Sonucu kanıtla doğruladı mı?

Bir repo göreviyle test etmemi istiyorsan yorumlara `TEST` yaz.
